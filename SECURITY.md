# Security Policy

> 🛒 **Official Gumroad store:** **https://ramsandesh.gumroad.com**

## Supported code

The latest code on the default branch is the actively maintained companion version.

## Reporting a security issue

Please avoid posting credentials, private data, access tokens, API keys, exploit details that could put real systems at immediate risk, or sensitive user information in a public issue.

For a security-sensitive report, contact:

**sanskarin@outlook.in**

Include enough information to reproduce the problem safely, such as the affected file, expected behavior, observed behavior, and a minimal benign reproduction.

## Repository security principles

- Never commit real secrets.
- Use synthetic or authorized data in examples.
- Keep tool execution explicit and allowlisted.
- Validate inputs at trust boundaries.
- Prefer least privilege.
- Record release identity and rollback information.
- Treat AI output as untrusted until validated for the intended use.
