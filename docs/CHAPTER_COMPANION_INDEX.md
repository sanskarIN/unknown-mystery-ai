# 120-Chapter Companion Index

> 🛒 Official book store: **https://ramsandesh.gumroad.com**

The complete book contains 120 chapters. This repository groups companion material by mastery block so readers can connect code and engineering patterns to the broader learning journey without reproducing the commercial manuscript.

| Chapters | Companion focus |
|---|---|
| 1–10 | AI foundations, Python-style experimentation, reproducibility |
| 11–20 | Data preparation, evaluation, classical ML thinking |
| 21–30 | Neural networks and deep-learning foundations |
| 31–40 | Training, optimization, representation learning, evaluation |
| 41–50 | Generative AI, sequence modeling, transformers, LLM foundations |
| 51–60 | Prompting, retrieval, RAG, evaluation, application patterns |
| 61–70 | Agents, tool orchestration, reasoning workflows, reliability |
| 71–80 | Probabilistic, Bayesian, causal, and uncertainty-aware AI |
| 81–90 | MLOps, serving, reproducibility, deployment, monitoring |
| 91–100 | Responsible AI, privacy, security, governance, evaluation |
| 101–110 | Research practice, systems thinking, advanced project work |
| 111–120 | Portfolio evidence, interviews, integration, final mastery capstone |

## Current repository mapping

- `src/umai/reproducibility.py` → experimentation and MLOps blocks.
- `src/umai/evaluation.py` → evaluation across ML and AI systems.
- `src/umai/retrieval.py` → RAG learning block.
- `src/umai/agents.py` → agent orchestration block.
- `src/umai/release.py` → release identity and deployment evidence.
- `src/umai/observability.py` → privacy-aware operational telemetry.

The companion repository will continue adding small, tested reference implementations while the official book remains available from **https://ramsandesh.gumroad.com**.
