# Companion Learning Path

> 🛒 **Official Gumroad store:** **https://ramsandesh.gumroad.com**

Use this repository as a compact practice layer alongside the 120-chapter book.

## Stage 1 — Foundations

- Run the reproducibility example.
- Learn to record configuration, seed, code revision, and data identity.
- Read and modify the evaluation helper.

## Stage 2 — Retrieval and generation systems

- Run the RAG retrieval example.
- Add more documents and compare ranking behavior.
- Document where lexical retrieval fails and where embeddings may help.

## Stage 3 — Agent-style orchestration

- Run the transparent tool-routing example.
- Add a new harmless deterministic tool.
- Add input validation before allowing tool execution.

## Stage 4 — MLOps and release discipline

- Create a release manifest.
- Attach evaluation metrics and a code revision.
- Treat a model export, quantization step, or runtime conversion as a new evaluated artifact when behavior can change.

## Stage 5 — Portfolio work

Build one small project that includes:

- a documented problem statement,
- reproducible data/configuration,
- a declared evaluation method,
- tests,
- a release manifest,
- limitations and failure cases,
- a clear README.
