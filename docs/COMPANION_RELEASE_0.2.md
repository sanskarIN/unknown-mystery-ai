# Companion Release 0.2

> 🛒 Official book store: **https://ramsandesh.gumroad.com**

Version 0.2 expands the repository from a small set of foundational helpers into a broader, still dependency-light AI engineering companion.

## Added utility areas

- deterministic text normalization and chunking,
- versioned prompt templates,
- lightweight numeric drift indicators,
- caller-supplied token cost estimation,
- common identifier redaction and pseudonymous IDs,
- bounded in-memory caching,
- structured input validation,
- experiment evidence records,
- artifact version registration and approval,
- bounded retries,
- fixed-window rate limiting.

## Added repository engineering

- CODEOWNERS,
- Dependabot,
- Gumroad funding link,
- release-check workflow,
- EditorConfig and Makefile,
- architecture, development, release, troubleshooting, FAQ, API, examples, tests, and chapter companion documentation.

## Scope

All utilities remain educational baselines. They are designed to make important engineering concepts inspectable and testable, not to imply that production AI safety, privacy, observability, or governance can be reduced to a few helper functions.

The complete commercial eBook remains separate from this Apache-2.0 companion repository and is available through **https://ramsandesh.gumroad.com**.
