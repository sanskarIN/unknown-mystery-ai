# Companion Release 0.5

> 🛒 Official book store: **https://ramsandesh.gumroad.com**

Version 0.5 focuses on repository quality and release evidence rather than adding another large surface area.

## Added

- public API compatibility smoke tests,
- cross-platform example smoke workflow,
- repository-local Markdown link validation,
- package metadata/version consistency validation,
- release artifact SHA-256 manifest generator,
- comprehensive quality workflow with build evidence,
- maintainer quality checklist and checksum documentation.

## Quality philosophy

A trustworthy learning repository should not only contain code; it should make correctness, provenance, boundaries, and maintenance visible. Automated checks reduce accidental breakage, while human review remains necessary for design, privacy, security, licensing, and educational quality.
