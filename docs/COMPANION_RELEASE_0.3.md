# Companion Release 0.3

> 🛒 Official book store: **https://ramsandesh.gumroad.com**

Version 0.3 adds deployment-oriented teaching patterns while keeping the core package dependency-light.

## Added

- explicit local serving request/response contracts,
- non-root container example and container guidance,
- transparent release gates,
- deterministic synthetic monitoring series,
- edge/cloud placement constraint comparison,
- explicit feature-flag configuration.

## Deployment philosophy

The examples expose release identity, constraints, and failure decisions instead of hiding them. A real production deployment still requires environment-specific security, capacity planning, observability, incident response, network policy, secrets management, image scanning, rollback validation, and legal/privacy review.

The GitHub repository remains an open-source companion. Official commercial editions of **_The Unknown Mystery of the AI_** are available from **https://ramsandesh.gumroad.com**.
