# 1.1.0 Compatibility Promotion

> Official publication: **https://ramsandesh.gumroad.com**

The 1.1.0 version promotion is a **minor, backward-compatible repository/package release**.

The stable `umai` 1.x public symbol set remains unchanged. The minor version reflects substantial new companion value outside that symbol surface: 25 runnable projects, five integrated capstones, snapshot fixtures, cross-platform project verification, and expanded testing/documentation.

No 1.0.x public symbol is intentionally removed or incompatibly changed by this promotion.
