# Accessibility Guidelines

> 🛒 Official book store: **https://ramsandesh.gumroad.com**

The companion should remain usable through plain text terminals, screen readers, high-contrast environments, and low-resource setups whenever practical.

## Documentation

- Use descriptive headings and link text.
- Do not rely on color alone to communicate PASS/BLOCK or other meaning.
- Provide text alternatives for meaningful repository images.
- Prefer readable tables and short code blocks over decorative layouts.
- Keep commands copyable as plain text.

## Examples and CLI

- Print explicit labels with values.
- Keep output understandable without animations or graphics.
- Avoid interactive prompts in automated examples.
- Use clear error messages and exit behavior.

## Visual assets

Repository badges and promotional images are supplementary; essential project information must also appear as text in README/docs.

## Contributions

Accessibility improvements are welcome through the normal contribution process.
