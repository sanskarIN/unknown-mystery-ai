# Companion Release 1.0

> 🛒 Official book store: **https://ramsandesh.gumroad.com**

Version **1.0.0** is the first stable milestone of the open-source companion repository for **_The Unknown Mystery of the AI_** by **Ram Sandesh**.

## Stable companion surface

The release includes dependency-light reference utilities for:

- reproducibility and fingerprints,
- classification and retrieval evaluation,
- lexical retrieval/RAG teaching patterns,
- transparent agent/tool orchestration,
- versioned prompts and regression fixtures,
- experiment and artifact evidence,
- release manifests, gates, comparisons, and structured evidence,
- deployment contracts, monitoring data, placement decisions, and feature flags,
- privacy redaction, validation, budgeting, bounded caches, retries, fallback, and rate limits,
- deterministic reporting and CLI project information.

## Quality and release evidence

The repository includes unit tests, cross-platform example smoke tests, package builds, metadata checks, internal documentation link checks, a public API snapshot, SHA-256 build manifests, CI workflows, security/support/contribution files, and stable API/deprecation policies.

## 1.x compatibility

Documented symbols exported through `umai.__all__` form the stable public surface for the 1.x line. Backward-incompatible changes should be reserved for a future major release except when security or material correctness requires faster action.
