# Social Link Policy

> Official publication: **https://ramsandesh.gumroad.com**

This repository intentionally avoids embedding change-prone personal social-media profile URLs in durable book metadata, release artifacts, source code, generated documentation, and long-lived publication assets.

## X / Twitter

Do **not** add an X/Twitter profile URL to durable project or publication files by default.

The maintainer may change social handles in the future, which can make old books, releases, screenshots, packages, and cached copies point to the wrong account. For that reason, the preferred permanent contact destinations are:

- GitHub profile: https://github.com/sanskarIN
- Repository: https://github.com/sanskarIN/unknown-mystery-ai
- Official book store: https://ramsandesh.gumroad.com
- Contact email: sanskarin@outlook.in

If an X/Twitter URL is ever used for a short-lived campaign, it should live in campaign-specific material rather than the master manuscript, release package, source package, or stable repository documentation.

## Rule for contributors

Please do not introduce `x.com` or `twitter.com` links into tracked repository files unless there is a documented, time-limited reason and a maintainer explicitly approves it.
