# Code of Conduct

> 🛒 **Official Gumroad store:** **https://ramsandesh.gumroad.com**

## Our standard

We want this repository to be a constructive learning space. Participants should:

- communicate respectfully,
- critique ideas and code rather than people,
- welcome learners with different experience levels,
- avoid harassment, discrimination, threats, and personal attacks,
- protect private information,
- give credit for others' work,
- keep technical discussions relevant and evidence-based.

## Unacceptable behavior

Unacceptable behavior includes harassment, hateful or demeaning content, deliberate intimidation, publishing another person's private information, spam, and repeated disruption of project collaboration.

## Enforcement

Project maintainers may edit, remove, or reject contributions and participation that violate these expectations. Serious or repeated violations may result in restrictions from project spaces.
